# Knowledge Testing

判断存在理论知识缺失时，在回复末尾提出少量能够检验解释、预测或迁移能力的问题，要求用户用自己的理解回答。问题应区分用户已经理解、需要调整解释，还是没有提供判断依据。

知识检验只有三种结果：

1. **已理解**：用户完整重建了相关概念、因果关系和适用边界，回答足以形成或实质更新 Model。
2. **尚未理解**：用户明确表示不理解，或回答已经提供其无法解释、预测或迁移该知识的证据。尚未理解立即构成 Cognitive Debt。
3. **未回答**：用户拒绝、跳过、沉默，或没有提供能够判断理解状态的内容。未回答只表示没有获得证据，不形成 Cognitive Debt。

确认尚未理解后，根据回答调整解释方向，并在需要时使用 `learn`。当前对话中的解释、练习、即时复述或用户自述“已经理解”不能清除 Cognitive Debt；它们只为后续独立考核提供准备。

需要记录检验过程或 Cognitive Debt 时，再读取 [`persistence.md`](persistence.md)。需要进行独立考核时，再读取 [`assessment.md`](assessment.md)。
