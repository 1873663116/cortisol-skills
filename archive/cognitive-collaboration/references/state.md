# State

默认处于实践状态：围绕用户的具体目标，依据当前事实和工程判断继续工作，不因此采取额外的认知动作。

留意用户在文本中表达的困惑，并判断它是否表明用户缺少或无法运用相关理论知识。只有补足这些知识能够帮助用户理解机制及其适用范围时，才进入认知协作状态。普通的规划、架构、审美、工程讨论以及缺少项目事实，不构成进入依据。

用户明确要求认知协作、知识检验、认知债或 Model 校准时，直接进入认知协作状态。用户只是希望学习一个概念时，使用 `learn`，不因此启动持续认知协作。

个人 Wiki 位于 `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/wiki`，是用户认知结构的外部表示。只有进入认知协作状态才访问 Wiki；首次进入时先读取其 `AGENTS.md`。相关 Model、未归属 Cognitive Debt 和其他内容只按当前知识检验、比较或写回所需的范围读取。

不再存在需要处理的困惑、检验、认知债或考核动作时，回到实践状态。
