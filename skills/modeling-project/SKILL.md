# 建模项目状态管理

本技能负责项目初始化、状态判断和资料导航。具体制作由当前任务承担；执行范围以用户授权为准。状态属于本次任务及其关联物件，设计、低模、高模、材质和光照属于任务阶段。

## 读取入口

先读取当前目录的 AGENTS.md、相关指导文档及当前工程事实。工程正在打开时，识别运行中版本与未保存修改。首次采用本技能或概念有歧义时读取[定义](references/definitions.md)。已有事实和已确认选择直接复用。

## 状态判断

每次收到新需求、设计决定或制作结果后，按下表从上到下选择第一个满足条件的状态；只判断本次任务需要的资料与依赖。

| 状态 | 进入条件 | 行为与退出条件 |
| --- | --- | --- |
| 待初始化 | 项目地图、宏观设计或微观架构缺失，或入口无法定位实际工程 | 按[初始化约定](references/initialization.md)补齐有效入口与已知事实；完成后重新判断。 |
| 待明确 | 存在现有依据无法解决、需用户取舍且影响当前工作的关键分歧 | 提供相关参考、图纸或粗模，只询问需要用户选择的问题；分歧解除后重新判断。可并行推进独立且已明确的内容。 |
| 待验证 | 已有修改尚无对应检查结论，或相关依赖改变使原检查失效 | 按[质量标准](references/quality.md)检查受影响内容；制作缺陷返回可制作修复，设计分歧返回待明确；通过后同步资料并重新判断。 |
| 可制作 | 当前目标与约束足以开展工作，且仍有授权内容未完成或有已确认制作缺陷待修复 | 交给具体制作任务；结合返工成本选择小样或批量处理。产生修改后进入待验证。 |
| 本次完成 | 本次结果已有对应验证，相关资料反映当前有效状态 | 报告结果及实际检查范围。新的输入触发重新判断。 |

待初始化允许记录明确的设计问题，无需先补完全部设计。讨论请求只分析状态与选择；写入、建模和下载等动作分别依据当前请求执行。

## 判断尺度

- 局部、可独立修改的选择可以用候选结果探索；会牵动形体、连接、UV 或烘焙的选择先验证关键关系。返工成本是情境判断，采用[定义](references/definitions.md)中的范围。
- SVG 或高模涉及比例与构造时，读取[质量标准的 SVG 与对应关系](references/quality.md#svg)；新增物件、连接或细分时，读取该文档的构造与拓扑条款。
- 同类批处理先用代表性物件验证方法；已验证规则可复用，新的表面类型和失败证据触发重评。
- 参数、参考图和具体工艺要求写在负责该内容的项目文档中。项目地图链接权威位置；参考图直接内嵌文档。
- 公共资产先检索再新增；项目专属修改留在项目内。库路径、导入方式与依赖遵循[初始化约定](references/initialization.md#shared-assets)。

## 更新边界

每轮仅更新受影响文档的当前有效表达；过程记录进入已有日志或验证报告。检查结论绑定实际受检版本与范围。技能只吸收可复用的判断规则，具体项目的尺寸、风格、引擎及光照约束保留在项目文档。
