# 建模资料与成果的质量标准

本文件提供当前任务可采用的验收条件。尺寸公差、曲面采样密度、显示距离与资源预算由项目需求和实际样片确定。具体技术实现由制作任务选择。

## SVG 与制作阶段

宏观 SVG 对应白盒，约束空间、大形与布局；微观 SVG 对应低模，约束部件、截面、关键尺寸与连接。两者分别内嵌宏观设计和微观架构文档。

高模的细分布线、支撑线、折痕与表面细节直接在 DCC 软件中制作和检查，无需绘制对应 SVG。高模沿用已确认图纸；外形尺寸或构造关系改变时，才更新受影响的图纸。

| 标准 | 合格表现 |
| --- | --- |
| 单位与坐标 | 图纸声明单位、视图方向和模型坐标对应。同一正交视图内横纵轴采用相同比例；不同视图的缩放关系明确。 |
| 比例真实 | 轮廓、尺寸标注和比例尺来自同一组尺寸或实际几何。长度标注对应真实端点，圆角标注对应所画半径。对 transform 之后的几何验证尺寸。 |
| 可缩放查看 | 工程视图有带单位的图形比例尺。图纸随显示尺寸变化时仍可比较；标注打印比例时同时指定物理输出尺寸。 |
| 视图一致 | 采用所需的正交视图与剖面；共有尺寸、轴线和接口位置一致。三视图用于表达三维关系，透视效果图承担视觉参考。 |
| 约束明确 | 必要外形、厚度、孔口、圆角和安装关系有可追溯定义。自由形体可以从粗模导出投影；简单构件用足以确定形状的尺寸和截面表达。 |
| 可审阅 | 线型、标注、图注可区分，重要尺寸无遮挡，文字在正常查看尺寸可读。参考图与图纸直接内嵌对应文档。 |
| 模型对应 | 制作与高模细化涉及尺寸关系时，以已确认 SVG 和约束核对实际模型；关键截面、半径、外形及安装位置在修改器求值后仍符合要求。 |

已有合格图纸可直接复用。比例或构造变化时更新受影响视图；颜色等不影响工程尺寸的修改沿用原图。模型中需要保留的人工设计修改先被识别，再更新对应依据，避免生成器覆盖当前设计。

## 参考与细节

- 参考说明采用的是形状、连接、材料、制造痕迹还是构图。图中不可成立的构造作为待解释问题处理，相关制作依赖清楚的设计选择。
- 整体参考无法解释部件时，寻找连接件、截面或相似工艺的局部参考。构造完成以必要部件、支撑、接触、厚度和收口成立为依据。
- 物件的可见连接、轮廓与关键阴影由适当几何表达；微表面细节根据观看条件与输出选择材质、贴花或高模。可控的插接和隐藏搭接按结构判断，重叠检测结果本身不能决定删除。
- 细节投入依据用户实际观察范围、构图作用和烘焙保留能力。隐藏内部结构按需要表达；物件近景用于检查制作缺陷。

## 拓扑与表面控制

好拓扑的判断依据是目标形体、稳定求值、合理编辑及输出对应。具体检查如下。

| 表面或问题 | 合格条件 |
| --- | --- |
| 基础网格 | 检查重复或退化几何、自交、法线方向及孔口连接。预期闭合的体积闭合；薄片或烘焙表面的开放边有明确用途。 |
| 平直表面 | 平面保持平直，控制面数量与构造复杂度相称。三角面或多边形可用于稳定平面填充；凹多边形与非共面面需要检查实际三角化结果。 |
| 连续曲面 | 曲率方向具有连续、可控的面带，极点与连接方式经细分结果验证。圆柱端面与侧面的控制分开考虑，圆周采样能够改善真实轮廓。 |
| 支撑与折痕 | 支撑线集中在需要控制曲率的区域；折痕对应明确的截面、硬边或倒角边界。平面填充线保持其填充用途；边属性按几何意义选择。 |
| 细分方式 | Simple 用于保留现有表面的加密，例如置换承载面；Catmull–Clark 用于需要平滑曲率的控制网格。实际截面与轮廓达到目标才算细化有效。 |
| 精确形状 | 折痕或支撑线控制平滑行为；圆弧半径、厚度及接合位置通过求值后的几何测量确认。参数曲线等其他构造方式可以承担精确曲面。 |
| 软质部件 | 控制网格允许目标鼓起、圆润和褶皱，约束位置来自缝线、锚固或造型要求。软垫与同物件的硬质框架分别判断。 |
| 自动重拓扑 | 输出作为候选，与原始形体核对孔口、薄壁、曲率和尺寸；规则构件可以直接重建。采用结果依据表现和可编辑性。 |
| 法线与倒角 | Sharp 控制着色分界，Crease 控制细分平滑，Bevel Weight 控制对应倒角选择或宽度。大平面与转折带的实际高光连续性需要看图验证。 |
| 置换与凹凸 | 真实位移有足够采样和实际尺度的幅度；Bump 改变着色法线。组合使用时核对频率、幅度、接缝及与邻近几何的关系。 |
| 输出对应 | 高模影响明显轮廓、开口或遮挡的变化需要输出低模相应表达；可投射的浅表细节可由烘焙承担，使用样片验证。 |

在实际使用的视口与渲染设置下检查修改器结果。密度、支撑线间距及折痕值按形状与误差调整；网格密度、四边面比例或修改器类型单独记录时仅代表相应事实。

## 验证证据

完整物件隔离检查用于连接、缺件、形体与破面；原位检查用于尺度、安装、遮挡及相邻关系；涉及材质、真实置换、玻璃或发光时检查相应渲染。大物件的局部检查按缺陷风险选择，已有有效证据只在相关修改后重做。

异常阴影通过关闭材质信号、查看基础几何和法线等对照定位原因。几何、法线、UV、材质与光照的检查分别说明证据，诊断结果决定修复范围。

验证记录绑定受检工程或资产版本、检查对象、求值条件和实际结果。自动检查通过、视觉检查完成、设计已认可分别表达。最终烘焙与导出需要相应输出样片；全场声明必须有覆盖该范围的证据。
