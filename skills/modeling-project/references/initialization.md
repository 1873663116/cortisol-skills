# 初始化与资产约定

## 当前目录与已有内容

初始化前识别当前目录、已有 AGENTS.md、文档、活动工程与资产位置。保留已有规则和合理布局，补齐缺项；有效文档通过链接复用。工程内容的迁移、删除及公共库改写分别需要对应任务范围。

空项目采用下列最小结构。目录在有实际内容时建立。

```text
项目根目录/
├─ AGENTS.md
├─ docs/
│  ├─ 宏观设计.html
│  └─ 微观架构.html
├─ work/          制作工程及其恢复副本
├─ assets/        项目专属资源和需要随项目携带的依赖
└─ output/        预览、烘焙与导出结果
```

宏观设计和微观架构的职责见[定义](definitions.md)。只写实际已知事实与当前设计问题。事实缺失时根据影响当前工作的程度澄清，初始化无需完成所有设计。

参考图直接内嵌到解释它的文档内，提供自包含呈现。参考图与工程图由对应文档承载，不建立独立目录。项目实际使用的贴图、贴花等制作资源保存在 assets/ 或原有资产位置。

读取包含大量内嵌图片的文档时，先提取正文与图注，按当前任务查看相关图片，避免将 Base64 图片数据作为正文加载。


## AGENTS.md 的内容

项目地图只包含可定位的当前入口和操作约定：

- 项目根、活动制作文件及使用它所需的软件信息；尚未创建工程时说明现状。
- 宏观设计、微观架构的相对链接，以及各自应在什么任务中读取。
- 工程、项目资产、输出与恢复副本的实际位置；低高模组织由相关文档或工程入口说明。
- 公共资产库的实际位置与已采用的导入方式；未配置时不记录。
- 当前已存在的制作或验证工具入口及其用途。工具参数通过工具自身获取，存在参数生成器时指向其参数来源。

完成依据：地图中的文件入口可解析；两类指导资料承载已知信息；已有工程与人工修改保留；参考图片能在文档内显示。动态对象数量通过工程读取，避免在地图重复维护统计表。

## 公共资产

先查 Blender 已登记的库及项目地图。已有可用资产优先复用；没有库时独立确定共享位置，初始化不触发批量下载或将当前场景整体迁入库。

公共库位于项目之外。Blender 资产存放在库内的 blend 文件中；原始贴图等资源保存于稳定位置或按需要打包。一个可复用物件以完整集合保存时，应保留内部层级、必要材料及依赖，并检查新工程中导入后的表现。

| 导入方式 | 使用条件 |
| --- | --- |
| Append | 项目需要独立修改资产；库后续更新与项目解耦。适合作为探索制作的默认建议。 |
| Link | 项目明确需要源库驱动更新，并接受其编辑与依赖约束。选择前确认该更新关系。 |

Append 复制 Blender 数据后的外部贴图路径仍需检查；项目可搬移性通过实际依赖检查、收集或打包验证。库中新增可复用资产另行整理，项目内修改保持本地，发布公共版本时保留来源与版本信息。

资产条目保留用于检索与选择的名称、预览、来源/许可、软件兼容信息和必要依赖。具体文件布局按现有库组织，公共库登记名称与磁盘位置分别记录。

官方参考：[资产库](https://docs.blender.org/manual/en/5.3/editors/preferences/asset_libraries.html)、[资产类型](https://docs.blender.org/manual/en/5.2/files/asset_libraries/introduction.html)。具体功能以当前安装版本为准。
